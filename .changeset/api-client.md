Add `@omnifront/api`: a fetch-based HTTP client with interceptors, typed `ApiError`, timeout and abort, opt-in retry, an XHR adapter for upload progress, `queryOptions` / `mutationOptions` for `@omnifront/query`, `withAuth` and `refreshOnUnauthorized` (store-driven auth), and a mock adapter for tests.
