Wave 2 of the UI kit (ADR-0014), "display and surface", in React, Vue and Angular: Typography, Paper, Card (header, content, actions, media), Divider, Avatar, Badge, SvgIcon, AppBar, Toolbar, List (item, button, icon, text, subheader), Table (container, head, body, footer, row, cell), Chip, Accordion and Tooltip. `@omnifront/ui` adds the stateless parts (`typographyPart`, `paperPart`, `cardPart`, `dividerPart`, `avatarPart`, `badgeMarkPart`, `svgIconPart`, `appBarPart`, `displayPart`) and the `createChip`, `createAccordion` and `createTooltip` machines, plus one CSS file per component.
