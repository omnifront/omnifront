# @omnifront/core

Framework-free primitives for omnifront: the Subscribable contract, notification batching, an injectable scheduler and selectors.

> Pre-release: not published to npm yet, and the API can still change.

```ts
import { derive, notifyManager, shallowEqual } from "@omnifront/core"
import { FakeScheduler } from "@omnifront/core/testing" // deterministic time in tests
```

Documentation: [omnifront docs](https://github.com/omnifront/omnifront/tree/main/apps/docs) (guides and API reference) and the [repository README](https://github.com/omnifront/omnifront#readme).
