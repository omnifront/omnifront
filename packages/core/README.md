# @unicore/core

Framework-free primitives for unicore: the Subscribable contract, notification batching, an injectable scheduler and selectors.

> Pre-release: not published to npm yet, and the API can still change.

```ts
import { derive, notifyManager, shallowEqual } from "@unicore/core"
import { FakeScheduler } from "@unicore/core/testing" // deterministic time in tests
```

Documentation: [unicore docs](https://github.com/AMHB-DEV/unicore/tree/main/apps/docs) (guides and API reference) and the [repository README](https://github.com/AMHB-DEV/unicore#readme).
